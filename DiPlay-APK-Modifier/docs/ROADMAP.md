# DiPlay 开发路线

## 阶段 1：APK 输入与静态分析
- SAF URI 安全复制到私有缓存
- SHA-256
- 包名、版本、SDK、组件与权限分析
- 签名证书信息读取

## 阶段 2：Manifest 兼容性研究
- 解码二进制 AndroidManifest.xml
- 识别 Android Auto 支持的应用类别与声明
- 形成只读差异报告
- 对不符合平台规则或会削弱应用安全边界的修改明确阻止

## 阶段 3：修改与签名
- 用户确认后生成独立副本，不覆盖原 APK
- 重打包完整性检查
- 独立签名与证书指纹展示

## 阶段 4：安装与车机验证
- 通过系统安装器交由用户确认
- 签名冲突与回滚提示
- 记录 Android Auto 版本、设备环境、识别与启动结果
